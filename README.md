# GOLFSwingAnalyzer APK Downloads

This public repository hosts **signed Android APK releases only**.

- [Latest GOLFSwingAnalyzer release](https://github.com/MasayukiKimura/GOLFSwingAnalyzer-Downloads/releases/latest)
- [Latest APK](https://github.com/MasayukiKimura/GOLFSwingAnalyzer-Downloads/releases/latest/download/GOLFSwingAnalyzer.apk)
- [Latest APK SHA-256 checksum](https://github.com/MasayukiKimura/GOLFSwingAnalyzer-Downloads/releases/latest/download/GOLFSwingAnalyzer.apk.sha256)

The APK files are produced by Codemagic from a separate private source repository, signed using a persistent Android signing key, and published here after hash and signing-certificate verification.

The links will be available **after the first successful release**.

**Android update notice:** If the existing installed app uses the original signing certificate, uninstall it before installing the first release signed with the new key. Uninstalling may erase application data. Later APKs signed with the same new key can be installed as updates.

No signing keys, passwords, or private application source code belong in this public repository.
